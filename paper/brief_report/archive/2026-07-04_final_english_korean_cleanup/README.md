# UAIS Brief Reports Package

## Upload This Folder Only

SNAPP 업로드에는 `submission/` 안의 파일만 사용한다.

| File | Upload role |
|---|---|
| `submission/manuscript_brief_report_final.docx` | Manuscript |
| `submission/cover_letter_brief_report.docx` | Cover Letter |
| `submission/title_page_brief_report.docx` | Title page / separate title document |
| `submission/supplementary.zip` | Supplementary material |

Note: `00_UPLOAD_TO_SNAPP/` and `upload_ready/` are old folders. They may remain only because Word is locking old manuscript files. Do not upload from them.

## Do Not Upload

| Folder/File | Purpose |
|---|---|
| `source/` | 원고 재생성용 소스와 figure. 제출 파일 아님. |
| `korean_reference/` | 한글 참고본. 제출 파일 아님. |
| `korean_final_report/` | 한글 최종 보고서. SNAPP 제출 파일 아님. |
| `00_UPLOAD_TO_SNAPP/` | 이전 업로드 폴더. 열려 있는 Word 파일 때문에 남아 있을 수 있으나 제출에 사용하지 않음. |
| `upload_ready/` | 이전 업로드 폴더. 열려 있는 Word 파일 때문에 남아 있을 수 있으나 제출에 사용하지 않음. |
| `archive/` | 이전 파일 보관용. 제출 파일 아님. |
| `SUBMISSION_CHECKLIST.md` | 제출 전 확인용 내부 문서. 제출 파일 아님. |
