# MSDS 점자 오류의 안전 리스크 사례집

**작성 일자**: 2026-05-12
**용도**: ① IEEE Access 논문 motivation 강화, ② 사회적 기업 신청서 사회적 영향 입증, ③ 점역사 감수 의뢰 시 우선 검토 항목 가이드, ④ 협업 기관 컨택 자료
**핵심 명제**: MSDS 점자에서의 단일 셀 오류가 화학사고 또는 응급처치 실패로 이어질 수 있음

---

## 0. 왜 이 사례집이 필요한가

일반 문학 점자에서 한두 글자 오류는 독자가 문맥으로 복원 가능. 그러나
MSDS는:

- **부정문 한 글자**가 행동 방향을 정반대로 바꿈
- **유사 물질명 한 글자**가 응급처치 절차를 완전 다른 것으로 바꿈
- **농도/단위 한 셀**이 노출 한계값을 잘못 알림
- **대문자 표시 한 셀**이 화합물 → 원소로 의미를 바꿈

이는 점자블록 한 칸의 오정렬이 시각장애 보행자를 차도로 떨어뜨릴 수 있는
것과 같은 구조 — **저빈도 고위험(low-incidence high-stakes)** 영역.

본 사례집은 본 프로젝트의 인코더(`pipeline/ko_braille.py`) 점검 과정에서
발견된 잠재 위험과 실제 화학산업 안전 데이터에 기반해 정리됨.

## 1. 부정문 오류 — 의미 정반대

### Case 1-1. "삼키지 마시오" → "삼키시오"

**원문**: GHS P301 "삼킨 경우: 즉시 의료기관에 연락하시오"
**관련 문구**: P264 "취급 후에는 손을 철저히 씻으시오"
**위험 시나리오**: 부정 표시 (`지 마`) 처리 오류로 점자 변환 시 "마"가 누락되거나 받침이 잘못 인코딩될 경우 → 사용자가 정반대 행동 수행 가능

**해당 인코더 위험**:
- 받침 ㅇ (ㄴ↔ㄹ↔ㅁ 혼동 시 다른 단어)
- 띄어쓰기 처리 (점자에서 의존명사 처리 시)

**실측 사고 가능성**: P301 표시 위반 시 화학물질 음용 후 잘못된 응급조치 →
부식성 화학물질의 경우 사망 가능

---

### Case 1-2. "공기 중에 노출되지 않도록" → "공기 중에 노출되도록"

**원문**: GHS P262 "눈, 피부, 의복에 접촉되지 않도록 하시오"
**위험**: 부정 어미 `-지 않-` 처리 오류

**해당 인코더 위험**:
- `않`이 받침 ㄶ (ㄴ+ㅎ 겹받침, 2셀)으로 처리되는데, 점역사가 이 표기를 읽고 다른 단어로 오인 가능성

---

## 2. 유사 물질명 단일 글자 차이

### Case 2-1. 벤젠 (Benzene, C₆H₆) vs 벤진 (Benzine, 석유 분류)

**차이**: ㅔ ↔ ㅣ 단 한 음소
**위험**:
- 벤젠: IARC Group 1 발암물질, LD₅₀ 930 mg/kg (rat oral)
- 벤진: 인화성 액체, 발암성 분류 없음 (혼합물)

**점자 처리 오류 시나리오**:
- "ㅔ" = ⠕ (1-3-4-5) vs "ㅣ" = ⠊ (1-3-5) — 점 한 개 차이
- 점역 결과 인쇄 시 점 누락 (엠보싱 불량) 또는 점 추가 (잉크 번짐) 시 의미 바뀜

**실측 사고 가능성**: 응급처치 시 "벤진 노출 → 인화 위험만 고려" vs "벤젠 노출 → 장기 발암 위험 모니터링 필요" 다른 대응

---

### Case 2-2. 일산화탄소 (CO) vs 코발트 (Co)

**차이**: 대문자 표시 1셀
**위험**:
- CO (Carbon monoxide): 흡입 위험, 응급처치 "맑은 공기로 이동"
- Co (Cobalt): 피부 자극, 응급처치 "다량의 물로 세척"

**점자 처리 오류 시나리오**:
- 대문자 indicator (⠠, 2-5-6 dots) 누락 시 `CO`가 `co`로 디코딩
- 본 프로젝트 인코더는 indicator를 영문 모드 진입 시 자동 처리하나, 영문 모드 외에서 출현 시 (혼합 텍스트) 누락 가능

**실측 사고 가능성**: 흡입 vs 피부 노출의 응급처치는 정반대 — 잘못된 처치 시 악화

---

### Case 2-3. 메탄올 (CH₃OH, 독성) vs 에탄올 (C₂H₅OH, 음용 가능)

**차이**: 메 ↔ 에 (자음 1개)
**위험**:
- 메탄올: 시신경 손상, 사망 (LD 30~100 mL)
- 에탄올: 일상적 음용, 독성 낮음

**점자 처리 오류 시나리오**:
- "메" = ㅁ초성(1-5) + ㅔ중성(1-3-4-5)
- "에" = ㅇ초성(1-2-4-5) + ㅔ중성(1-3-4-5)
- 초성 셀 한 개 차이 — 엠보싱 불량 시 혼동

**실측 사고 가능성**: 한국에서 메탄올 음용 사고 빈번 발생 사례 존재 (위조 주류 사건). MSDS 정보 오인 시 동일 사고 가능.

---

## 3. 화학식 / 단위 표기 오류

### Case 3-1. H₂SO₄ vs H2SO4 vs HSO₄

**원문**: 황산 분자식
**위험**:
- H₂SO₄ (Unicode 아래첨자): 점자 변환 시 첨자 indicator 없음 → 깨짐
- H2SO4 (ASCII 숫자): 인코더가 숫자 모드 진입 → `H⠼2 S O⠼4` 형태로 변환 → 점역 후 해석 시 `H` 다음 숫자 "2"로 읽힘 → 정상
- 그러나 HSO₄ (이온, 황산수소이온)와 분자식 자체가 다름 — 변환 단계 이전에 원본 데이터 일관성 문제

**현재 인코더 갭** (자가 점검 리포트 §2.5 참조):
- Unicode 첨자(₀-₉) 미처리 → 데이터에 섞여 있으면 깨짐

**위험**: 농도/조성 정보 누락 → 노출 한계값 계산 오류

---

### Case 3-2. "1 mg/L" vs "1 ㎎/L" vs "1mg/L"

**위험**: 단위 점자 표기 + 띄어쓰기

**점자 처리 오류 시나리오**:
- ㎎ (전각 기호, U+339C) — 인코더 미처리 → 원문 그대로 통과 → 점자 디스플레이에서 깨짐
- "1mg/L" (붙여쓰기) — 숫자 모드 후 영문 모드 전환 시 indicator 위치 모호
- 점역사 검수 없이는 가독성 보장 불가

**실측 사고 가능성**: 노출 한계값 (TLV-TWA, STEL) 잘못 읽기 → 작업 중지/계속 결정 오류

---

### Case 3-3. 농도 "0.05 mg/L" vs "0.5 mg/L"

**위험**: 소수점 위치 1자리 차이가 노출 한계 10배 차이

**점자 처리 오류 시나리오**:
- 소수점 `.` = ⠲ (2-5-6) — 현재 인코더에서 다른 부호와 혼동 가능 (괄호/따옴표 갭 영향 받음)
- 숫자 점자 중간에 소수점 처리 일관성 필요

**실측 사고 가능성**: 안전 농도의 10배 초과 노출 → 급성 중독

---

## 4. 괄호 / 명명법 오류

### Case 4-1. "벤조[a]피렌" vs "벤조[e]피렌"

**원문**: 다환방향족탄화수소 (PAH)
**위험**:
- 벤조[a]피렌: IARC Group 1 (사람에게 발암성 확실)
- 벤조[e]피렌: IARC Group 3 (분류 불가)

**점자 처리 오류 시나리오** (자가 점검 §2.1 참조):
- 현재 인코더에서 `[` `]` 처리 없음 (`KO_PUNCT_BRAILLE`에 없음) → 원문 통과 → 점자 디스플레이 깨짐
- 점역사가 손으로 작성 시 대괄호 표기 별도 필요

**실측 사고 가능성**: 발암성 모니터링 누락

---

### Case 4-2. "1,2-디클로로에탄" vs "1,1-디클로로에탄"

**위험**: 위치 번호 차이 (이성질체)
- 1,2-DCE: IARC Group 2B (가능성 있음)
- 1,1-DCE: 분류 다름, 독성 데이터 다름

**점자 처리 오류 시나리오**:
- 쉼표 `,` 처리는 정상 (⠂ 5 dot)
- 그러나 숫자 모드 중간 쉼표가 숫자 indicator 모드 재설정에 영향 줄 수 있음 — 검증 필요

---

## 5. GHS 그림문자 변환 오류

### Case 5-1. GHS01 (폭발성) vs GHS02 (인화성)

**프로젝트 구현**: 그림문자 코드 → 한국어 설명 텍스트 → 점자

**위험**:
- 변환 매핑 오류 시 폭발성 위험을 인화성으로 잘못 안내 가능
- 폭발성: 정전기 방지, 충격 회피 필요
- 인화성: 점화원 회피, 환기 필요

**현재 매핑** (`scripts/ghs_braille.py` 참조 필요):
- 정적 룩업 테이블로 처리 → 룩업 자체 검증 필요

**실측 사고 가능성**: 보호장구 선택 / 작업 방식 결정 오류

---

## 6. 점역 인쇄 단계 (엠보싱) 오류

자동 변환은 정확해도 점자 엠보싱 단계에서 발생 가능:

| 오류 유형 | 결과 |
|---------|------|
| 점 누락 (엠보싱 압력 부족) | 자모 변형 → 다른 글자 |
| 점 추가 (잉크/먼지 부착) | 자모 변형 → 다른 글자 |
| 셀 간격 불일치 | 단어 경계 혼동 |
| 페이지 휨/주름 | 손가락 읽기 실패 |
| 양면 인쇄 시 반대면 점 간섭 | 가독성 저하 |

본 프로젝트 범위 외이나, **납품 시 점자 출판사/엠보싱 기관 협업 필수** 근거.

## 7. 통계적 위험 평가

(추정치 — 점역사 감수 후 정밀화 예정)

**가정**:
- 화학사고: 한국 연 평균 ~50건 (안전보건공단)
- 응급실 화학물질 노출: 연 ~5,000건 (질병관리청)
- 시각장애인 노동인구: ~5만명 (한국시각장애인연합회)
- 시각장애인 화학산업 종사자: 추정 불가 (인프라 부재로 진입 차단)

**현재 시나리오 (점자 정보 부재)**:
- 시각장애인은 화학물질 취급 현장 진입 자체가 봉쇄
- → 사고 통계에 잡히지 않음 = 위험 없음으로 오인 → 인프라 미구축 → 진입 차단 (자기충족 예언)

**본 프로젝트 후 시나리오 (점자 정보 제공)**:
- 시각장애 노동자/감독관/연구자가 화학 정보에 접근 가능
- 단, 점자 오류율이 기준치 이하여야 함 — **이게 바로 점역사 감수가 필요한 이유**

**기준치 권고** (점역사 감수 시 합의):
- 안전 직결 정보 (GHS H/P, 응급처치): **오류율 < 0.1 cells per 1,000**
- 일반 정보 (제품명, 회사명): **오류율 < 1.0 cells per 1,000**
