# 공공데이터 활용신청 — 붙여넣을 문구

신청 화면에서 그대로 복사해 쓸 수 있게 정리한다. 문구는 실제로 할 일과 맞춘다.
승인은 신청서를 근거로 나므로, 나중에 하는 일이 여기 적힌 것과 다르면 재신청
사유가 된다.

공통 사항:
- **활용목적 구분**: `연구(논문 등)`
- **개발계정**으로 신청 (자동승인). 운영계정은 심의 대상이고 이 연구에는 불필요
- 기존 인증키에 서비스가 추가되며 새 키는 발급되지 않음

---

## KOSHA 국내재해사례 (data.go.kr 15121001)

https://www.data.go.kr/data/15121001/openapi.do

### 활용목적 상세 (그대로 붙여넣기)

```
시각장애인이 산업안전 정보를 점자로 읽을 수 있게 하는 연구에 활용합니다.

앞선 연구에서 화학물질 안전보건자료(MSDS) 48,966종을 2017년 개정 한국 점자
규정에 따라 점자로 변환하여 국제 학술지에 게재하였고(Universal Access in the
Information Society, 2026), 변환 결과를 공개 데이터셋으로 배포하였습니다.

이번 연구는 그 변환 체계가 안전 분야의 다른 문서 형태에도 적용되는지를
검증하는 후속 연구입니다. 의약품 허가정보와 농약 등록정보를 이미 확보하여
검증하였으며, 국내재해사례는 세 번째 문서 형태로서 필요합니다.

앞의 두 자료는 항목이 정해진 표 형태인 반면 재해사례는 사고 경위와 원인을
서술한 자유 형식 문장입니다. 문서 형태가 다른 자료에서도 동일한 점자 변환기가
규정을 지키며 동작하는지 확인하는 것이 이 연구의 핵심 질문이며, 서술형 자료가
없으면 그 질문에 답할 수 없습니다.

또한 앞선 연구가 다룬 화학물질 정보와 실제 사고 기록을 같은 점자 체계로
연결하면, 시각장애인 근로자와 안전보건 교육을 위한 자료로 쓰일 수 있습니다.

활용 방식은 다음과 같습니다.
- API로 재해사례 본문을 수집하여 점자로 변환
- 변환 정확도(왕복 검증), 2017년 점자 규정 준수 여부, 원문 대비 점자 분량을 측정
- 측정 결과를 학술논문으로 발표하고, 변환 코드를 공개 저장소에 게시

수집한 원문 자체를 재배포하지 않으며, 변환 결과와 통계, 변환 코드만 공개합니다.
상업적 목적으로 이용하지 않습니다. 호출은 연구에 필요한 범위로 제한하고
요청 간격을 두어 서비스에 부담을 주지 않도록 합니다.
```

### 짧은 버전 (글자 수 제한이 있을 때)

```
시각장애인용 산업안전 정보 점자 변환 연구에 활용합니다. 앞선 연구에서 MSDS
48,966종을 2017년 한국 점자 규정으로 변환하여 국제 학술지에 게재하였고
(UAIS 2026), 이번에는 같은 변환 체계가 다른 문서 형태에도 적용되는지
검증합니다. 의약품·농약 자료는 항목이 정해진 표 형태여서, 사고 경위를 서술한
재해사례가 세 번째 문서 형태로 필요합니다. 변환 정확도와 점자 규정 준수를
측정하여 논문으로 발표하고 코드를 공개합니다. 원문은 재배포하지 않으며
비영리 연구 목적으로만 사용합니다.
```

## 참고 — 이미 신청한 것

| 데이터 | 포털 | 서비스 | 상태 |
|---|---|---|---|
| 의약품 제품 허가정보 | data.go.kr | DrugPrdtPrmsnInfoService07 | 인가됨 |
| 의약품개요정보(e약은요) | data.go.kr | DrbEasyDrugInfoService | 인가됨 |
| 농약 등록정보 | 식품안전나라 | I1910 | 2026-08-26 승인 |

식약처 자료는 **식품안전나라**(openapi.foodsafetykorea.go.kr), KOSHA 자료는
**data.go.kr** 이다. 두 포털은 키가 별개이므로 서로의 서비스를 부르지 못한다.

## 신청 뒤 확인

승인되면 알려주십시오. 아래로 즉시 확인합니다.

```
python scripts/paper2_fetch_incidents.py --check
```

`INFO-110`(활용신청 내역 없음)이나 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`가
나오면 아직 반영 전입니다. 포털에 따라 승인 후 반영까지 몇 분 걸립니다.
